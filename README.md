# Lunar Patrol

Jogo de arcade em HTML5 canvas inspirado em **Moon Patrol** (Irem, 1982), feito como PWA: instala no celular, abre em tela cheia, travado na horizontal e funciona offline.

**Jogar:** https://ronydiv.github.io/lunar-patrol/

## Instalar no celular
- Android (Chrome): abra o link, toque em ⋮ → "Instalar app".
- iPhone (Safari): Compartilhar → "Adicionar à Tela de Início".

## Controles
- Teclado: ←/→ velocidade, ↑/Z/Espaço pulo, X tiro, P pausa, M som.
- Toque: botões ◀ ▶, PULO e TIRO na tela.

## Arquivos
- `index.html`: o jogo inteiro (código, sprites e som sintetizado).
- `manifest.webmanifest`: tela cheia + orientação horizontal.
- `sw.js`: cache para jogar offline.
- `icons/`: ícones do app.
